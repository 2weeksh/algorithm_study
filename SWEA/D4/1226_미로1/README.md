# [D4] 1226. [S/W 문제해결 기본] 7일차 - 미로1

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=
- 분류: BFS, 그래프 탐색
- 풀이 날짜: 2026-11-18

## 접근 방법

- 출발점 (1, 1)에서 BFS 시작
- `visited` 배열, 상하좌우 `dx`, `dy`, `deque` 사용
- 이웃 칸이 3(도착)이면 성공, 0(길)이고 방문하지 않았으면 큐에 넣고 바로 방문 처리
- 큐가 빌 때까지 도착하지 못하면 0 출력

## 시간 복잡도

O(16 × 16): 각 칸을 최대 한 번씩 방문

## 회고 / 막혔던 점

- BFS에서는 큐에 **넣자마자** 방문 처리해야 함
  → 꺼낼 때 처리하면 같은 칸이 큐에 중복으로 들어갈 수 있음
  → 최단 거리 문제라면 거리 기록(`dist[ny][nx] = dist[y][x] + 1`)도 이때 함
- `deque.popleft()`는 O(1), 리스트의 `pop(0)`은 O(N)
- 공백 없이 들어오는 줄은 `split()` 대신 `strip()`
  → 문자열은 한 글자씩 순회되므로 `map(int, "1210")` → `[1, 2, 1, 0]`
  → `strip()`은 `readline`이 붙여 오는 `\n`을 없앰 (없으면 `int('\n')`에서 ValueError)
- [S/W 문제해결 기본] 시리즈는 T 없이 10케이스 고정, 각 케이스가 번호로 시작
- 테두리가 모두 벽이라서 범위 검사 없이도 됐지만, 다른 문제에서는 범위 검사가 필요함
