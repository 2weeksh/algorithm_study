# [D4] 1210. [S/W 문제해결 기본] 2일차 - Ladder1

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=
- 분류: 구현, 시뮬레이션
- 풀이 날짜: 2026-11-20

## 접근 방법

- 도착 지점(마지막 줄의 `2`)에서 출발해 거슬러 올라감
- 매 칸에서 좌 → 우 → 상 순서로 확인
  - 범위 안이고 값이 `1`인 첫 방향으로 이동
  - 떠나는 칸은 `+5`로 표시해서 다시 돌아가지 않게 함
- 0번째 행에 도착하면 그때의 열 번호가 정답

## 시간 복잡도

O(100 × 100): 각 칸을 최대 한 번 지나감

## 회고 / 막혔던 점

- 위에서 내려가면 출발점 100개를 다 시뮬레이션해야 하지만, 도착점에서 올라가면 경로가 하나뿐
  → "답이 정해진 쪽에서 거꾸로 출발하기"
- 좌우를 위보다 먼저 확인해야 함 (가로줄이 있으면 반드시 타야 하므로 방향 순서가 중요)
- 범위 확인
- 왔던 곳을 표시하지 않으면 좌우를 무한 왕복함
  → 별도 visited 배열 대신 맵 값을 바꿔서 처리
- [S/W 문제해결 기본] 형식: T 없이 10케이스, 각 케이스가 번호로 시작
