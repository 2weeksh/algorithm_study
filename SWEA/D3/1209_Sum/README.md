# [D3] 1209. [S/W 문제해결 기본] 2일차 - Sum

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=
- 분류: 구현, 2차원 배열
- 풀이 날짜: 2026-11-20

## 접근 방법

- 행의 합: `sum(maps[i])`
- 열의 합: `zip(*maps)`로 행과 열을 바꾼(전치) 배열을 만들어 `sum(c_maps[i])`
- 대각선 두 개: 반복문 한 번에 `maps[i][i]`(↘)와 `maps[i][99-i]`(↙)를 같이 더함
- 모든 합 중 최댓값 출력

## 시간 복잡도

O(100 × 100)

## 회고 / 막혔던 점

- 반복문 한 번으로 대각선 두 개를 동시에 계산
- `zip(*maps)`로 행과 열 바꾸기 → 열의 합도 행의 합과 같은 코드로 구함
- 슬라이싱을 붙이느냐, 어디에 붙이느냐에 따라 결과가 달라짐
  - `zip(*maps)` → 전치
  - `zip(*maps[::-1])` → 시계 방향 90도 (1961)
  - `list(zip(*maps))[::-1]` → 반시계 방향 90도 (시계 방향 90도를 3번 돌린 것과 같음)
