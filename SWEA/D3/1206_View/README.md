# [D3] 1206. [S/W 문제해결 기본] 1일차 - View

- 분류: 구현
- 풀이 날짜: 2026-11-20

## 접근 방법

- 2번 ~ N-3번 건물마다 양옆 2칸씩(총 4개) 중 가장 높은 건물을 구함
- 현재 건물이 그보다 높으면, 높이 차이만큼이 조망권이 확보된 세대 수 → 누적

## 시간 복잡도

O(N)

## 회고 / 막혔던 점

- 특별히 막힌 점 없음
- [S/W 문제해결 기본] 형식이지만 각 케이스 첫 줄이 번호가 아니라 건물 개수 → 출력 번호는 직접 셈
