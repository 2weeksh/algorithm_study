# [D3] 1215. [S/W 문제해결 기본] 3일차 - 회문1

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=
- 분류: 구현, 문자열, 스택
- 풀이 날짜: 2026-11-20

## 접근 방법

- 모든 칸 `(y, x)`에서 하, 우 두 방향으로 길이 N만큼 확인
- 스택으로 회문 판별
  - 앞쪽 절반은 스택에 push
  - 뒤쪽 절반은 pop 하면서 현재 글자와 비교, 다르면 바로 중단
  - 홀수 길이면 가운데 글자는 건너뜀
  - 끝까지 같고 스택이 비면 회문
- N = 1이면 모든 칸이 회문이므로 64개

## 시간 복잡도

O(64 × 2 × N)

## 회고 / 막혔던 점

- 방향은 하, 우 두 개면 충분함
  → 회문은 뒤집어도 같아서 상, 좌까지 보면 같은 회문을 두 번 셈
- N = 1일 때 회문 개수는 64개 (예외 처리)
- 스택에 넣고 pop으로 빼면서 비교하는 방식으로 구현
- 다른 방법: 가로는 `row[x:x+N]`, 세로는 `zip(*maps)`로 전치한 뒤 같은 방식으로 잘라서 `s == s[::-1]`로 비교
