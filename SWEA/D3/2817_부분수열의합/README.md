# [D3] 2817. 부분 수열의 합

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=
- 분류: 백트래킹, DFS, 재귀
- 풀이 날짜: 2026-11-18 (재풀이)

## 접근 방법

- 각 원소마다 "선택 안 함 / 선택함" 두 갈래로 나누는 DFS
- `DFS(i, total)`: i번째 원소를 볼 차례, 지금까지의 합이 total
- 종료 조건을 맨 처음에 작성
  - `total > K`이면 0 반환 (가지치기)
  - `i == N`이면 `total == K`일 때 1, 아니면 0 반환
- 두 갈래의 결과를 더해서 return → 전역 카운터 없이 경우의 수를 셈

## 시간 복잡도

O(2ᴺ): N ≤ 20이면 최대 약 100만, 가지치기로 더 줄어듦

## 회고 / 막혔던 점

- 재귀를 호출할 때 `total + arr[i]`처럼 인자로 넘기면, 돌아왔을 때 호출한 쪽의 값이 그대로라서 자동으로 원상복구됨
  → 전역 변수나 리스트를 직접 바꾸면 재귀 후에 `-=`나 `pop()`으로 직접 되돌려야 함
- 선택 안 할 때와 할 때로 분기하면 두 결과를 합쳐서 return 해야 함
- DFS나 재귀를 짤 때는 종료 조건 if문부터 작성
- `total > K` 가지치기는 수열이 전부 자연수라서 가능함 (음수가 있으면 K를 넘었다가 다시 내려올 수 있음)
