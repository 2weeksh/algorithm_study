# [D3] 1873. 상호의 배틀필드

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=
- 분류: 구현, 시뮬레이션
- 풀이 날짜: 2026-11-19

## 접근 방법

- 맵을 `list(input().strip())`로 받아 칸을 수정할 수 있게 함
- 전차(`^ v < >`) 위치를 찾고, 명령을 하나씩 처리
  - 이동(`U D L R`): 방향을 바꾸고, 다음 칸이 범위 안이면서 평지 `.`이면 이동
  - 발사(`S`): 전차 방향으로 포탄을 한 칸씩 진행
    - 벽돌 `*` → `.`로 부수고 멈춤 / 강철벽 `#` → 멈춤 / 맵 밖 → 사라짐 / 물 `-`, 평지 `.` → 통과
- 출력은 `"".join(maps[i])`로 공백 없이

## 시간 복잡도

O(H×W + N×max(H, W)): 전차 찾기 + 명령마다 포탄이 최대 한 줄을 지나감

## 회고 / 막혔던 점

- 공백 없이 출력할 때는 `"".join(maps[i])` 사용
- 문자열은 불변이라 `maps[r][c] = '.'`가 안 됨 → 수정할 맵은 리스트로 받기
- 2차원 배열에서는 인덱스 범위부터 먼저 검사 (단락 평가)
- 방향마다 블록을 복붙해서 풀었는데, 블록끼리 다른 부분만 딕셔너리로 뽑으면 코드가 짧아짐
  → 전차 모양 → 방향 번호 (`{'^': 0, ...}`), 명령 → 방향 번호와 전차 모양
  → 복붙하면 한 곳만 고치고 나머지를 빼먹는 실수가 생기기 쉬움
- 놓치기 쉬운 예외는 문제를 읽을 때 체크리스트로 적어 두고, 다 짠 뒤 하나씩 대조하기
  - 못 움직여도 방향은 바뀜 (방향 갱신을 이동 if문 바깥에 둬야 함)
  - 전차는 평지로만 이동, 포탄은 물을 통과, 강철벽은 안 부서짐
