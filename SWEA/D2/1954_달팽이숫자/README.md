# [D2] 1954. 달팽이 숫자

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=
- 분류: 구현, 시뮬레이션
- 풀이 날짜: 2026-11-16

## 접근 방법

- 4방향 이동을 `dx`, `dy` 배열로 설정 (오른쪽 → 아래 → 왼쪽 → 위, 시계 방향)
- 다음 칸이 범위를 벗어나거나 이미 채워져 있으면 방향 전환
- 방향 인덱스는 `dir % 4`로 계산해서, 숫자가 3보다 커져도 0~3 안에서 순환

## 시간 복잡도

O(N²): N×N 칸을 한 번씩 채움

## 회고 / 막혔던 점

- if문 조건은 왼쪽부터 검사하고, 중간에 거짓이면 뒤는 검사하지 않음 (단락 평가)
  → 범위 검사를 `maps[ny][nx]`보다 앞에 둬야 인덱스 문제가 안 생김
  → 파이썬은 `maps[-1]`이 에러 없이 마지막 줄을 가리키므로, 순서가 틀리면 에러 없이 틀린 답이 나올 수 있음
- 막혔을 때 한 번 꺾으면 그다음 칸은 항상 비어 있으므로, 방향 전환은 `while`이 아닌 `if` 한 번이면 충분
