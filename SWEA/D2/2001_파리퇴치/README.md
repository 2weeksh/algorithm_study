# [D2] 2001. 파리 퇴치

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=
- 분류: 완전탐색, 2차원 배열
- 풀이 날짜: 2026-11-17

## 접근 방법

- for문 4번
  - 바깥 2개: M×M 윈도우의 시작 위치 `(r, c)` 지정, 범위는 `N-M+1`
  - 안쪽 2개: 윈도우 안의 값을 `arr[r+y][c+x]`로 더함 (시작점 + 오프셋)
- 윈도우마다 합을 구해서 최댓값 갱신

## 시간 복잡도

O((N-M+1)² × M²): N ≤ 15라서 충분히 빠름

## 회고 / 막혔던 점

- 시작점 범위를 `N-M+1`로 잡아야 윈도우가 배열 밖으로 안 나감
- `current_total = 0`은 시작점이 바뀔 때마다 초기화되도록 바깥 2중 for문 안에 둬야 함
- N이 커지면 2차원 누적합으로 윈도우 합을 O(1)에 구할 수 있음
