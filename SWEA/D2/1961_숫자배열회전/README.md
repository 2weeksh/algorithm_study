# [D2] 1961. 숫자 배열 회전

- 링크: https://swexpertacademy.com/main/code/problem/problemDetail.do?contestProbId=
- 분류: 구현, 2차원 배열
- 풀이 날짜: 2026-11-17

## 접근 방법

- 90도 회전 함수 하나를 만들고 90 → 180 → 270으로 이어서 적용
- 90도 회전: `[list(row) for row in zip(*maps[::-1])]`
  - `maps[::-1]`: 행 순서를 뒤집음 (위아래 반전)
  - `zip(*...)`: 같은 열끼리 묶음 (전치, 열이 행이 됨)
  - 위아래 반전 후 전치하면 시계 방향 90도 회전
- 출력은 각 행의 숫자를 `join`으로 붙이고, 90/180/270도 결과를 공백으로 구분

## 시간 복잡도

O(N²): 회전 한 번에 N×N, 3번 수행

## 회고 / 막혔던 점

- `join`은 문자열만 받음 → 숫자 리스트에 쓰려면 `map(str, ...)` 필요 (튜플에도 바로 쓸 수 있음)
- 계산을 안 할 거면 `list(map(int, ...))` 말고 `input().split()`으로 문자열 그대로 받기
  → int로 바꿨다가 str로 되돌리는 과정이 필요 없어짐
- 270도 회전에서 아직 만들지 않은 변수를 회전시키는 오타로 NameError가 남
