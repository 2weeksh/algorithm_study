# algorithm_study

SW Expert Academy(SWEA) 문제 풀이 기록 (Python)

## 폴더 구조

```
SWEA/
├── _template/            # 새 문제 시작할 때 복사해서 사용
└── D1 ~ D8/
    └── 문제번호_문제이름/
        ├── Solution.py   # 풀이
        ├── input.txt     # 샘플 입력 (로컬 테스트용)
        └── README.md     # 접근 방법, 회고 (선택)
```

## 새 문제 시작하기

```bash
cp -r SWEA/_template "SWEA/D3/1206_View"
```

`input.txt`에 샘플 입력을 붙여넣고 `python Solution.py`로 실행하면 됩니다.
`Solution.py`는 `input.txt`가 있을 때만 그 파일을 읽으므로 수정 없이 그대로 제출해도 됩니다.
